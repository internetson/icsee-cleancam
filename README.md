# CleanCam OS

<p align="center">
  <b>Открытая кастомная прошивка для Wi-Fi камер Xiongmai / ICSee на процессоре Goke GK7201V300</b><br>
  <i>Без китайских облаков, без телеметрии, с нативным RTSP HEVC, полноценным ONVIF 2.0 / PTZ и современным WebUI</i>

## 📋 О проекте

**CleanCam OS** — это альтернативная легковесная прошивка для поворотных Wi-Fi IP-камер китайского производства на базе чипсета **Goke GK7201V300** (Wi-Fi модуль **SSV6158M** / сенсор SC2336 / SC3336), продаваемых под брендом **ICSee / Xiongmai (XM)**.

Оригинальная заводская прошивка страдает от жесткой привязки к китайским облачным сервисам (XMeye), постоянной передачи телеметрии, закрытого протокола, отсутствия стандартного веб-интерфейса (требующего древний плагин ActiveX в Internet Explorer), кривой реализации ONVIF и высоких задержек.

**CleanCam OS решает эти проблемы:**
- 🚫 **100% приватность:** полностью вырезаны китайские облачные службы, P2P-трекеры (`cloud.xmeye.net`, `push.umeye.cn`, `secu100.net`) и сотовая телеметрия.
- 🚀 **Двухпоточный RTSP сервер (`xm_rtspd`):** прямой захват H.265/HEVC потоков из видеоподсистемы с нулевой задержкой и минимальной нагрузкой на CPU/RAM.
- 🎥 **Полноценный ONVIF 2.0 / PTZ:** полная совместимость с **Frigate NVR** (автослежение, детекция), **Home Assistant**, **Shinobi**, **Agent DVR** и **ONVIF Device Manager (ODM)**.
- 🌐 **Современный HTML5 Web-интерфейс (порт 80):** работает во всех современных браузерах и смартфонах без плагинов.
- 🕹️ **Управление PTZ:** виртуальный джойстик в браузере, управление стрелками клавиатуры (`↑`, `↓`, `←`, `→`), 16 слотов пресетов/позиций.
- 💡 **Управление подсветкой:** переключение умного двойного света (Dual-Light), инфракрасного и белого светодиодного прожектора вручную или по расписанию.
- 🖱️ **Интерактивный OSD:** перемещение штампа даты/времени и имени камеры мышью по экрану превью в реальном времени.
- 📶 **Встроенный менеджер Wi-Fi:** сканирование эфира, удобное копирование и переключение на домашнюю сеть прямо из веб-интерфейса.
- 🔘 **Аппаратная кнопка Reset (`xm_resetd`):** 10-секундное удержание кнопки сбрасывает настройки сети и пароли к значениям по умолчанию.
- 🔓 **Полный Root-доступ:** открытый порт Telnet 23 (логин `root` без пароля).

## 📡 Сетевые сервисы и порты

| Протокол / Сервис | Порт | Путь / Параметры | Описание |
|---|---|---|---|
| **WebUI (HTTP)** | `80` (и `8080`) | `http://<IP>/` | Веб-интерфейс управления камерой (логин: `admin`, пароль: `admin`) |
| **RTSP Main** | `554` | `rtsp://<IP>:554/live/ch0` | Основной поток (1920x1080 @ 12 fps, HEVC/H.265) |
| **RTSP Sub** | `554` | `rtsp://<IP>:554/live/ch1` | Дополнительный поток для детекции (800x448 @ 12 fps, HEVC/H.265) |
| **ONVIF SOAP** | `8899` | `http://<IP>:8899/onvif/device_service` | ONVIF Device, Media 1.0, PTZ 2.0 (авторизация `admin/admin`) |
| **WS-Discovery** | `3702` (UDP) | Мультикаст | Автообнаружение камеры в локальной сети |
| **Telnet (Root)** | `23` | Логин: `root`, пароль: *пустой* | Системный шелл Linux BusyBox |

## 🔌 API эндпоинты (для Home Assistant и автоматизаций)

Камера предоставляет легковесные HTTP API для интеграции с умным домом:

### 1. Управление подсветкой (`/cgi-bin/light`)
* `GET /cgi-bin/light?action=white_on` — принудительно включить белый прожектор.
* `GET /cgi-bin/light?action=white_off` — выключить белый прожектор.
* `GET /cgi-bin/light?action=ir_on` — принудительно включить ИК-подсветку (ночной ч/б режим).
* `GET /cgi-bin/light?action=ir_off` — выключить ИК-подсветку (дневной цветной режим).
* `GET /cgi-bin/light?action=auto` — вернуть автоматический умный режим (Dual-Light).

### 2. Управление поворотным приводом PTZ (`/cgi-bin/ptz`)
* `GET /cgi-bin/ptz?action=up&speed=5` — наклон вверх
* `GET /cgi-bin/ptz?action=down&speed=5` — наклон вниз
* `GET /cgi-bin/ptz?action=left&speed=5` — поворот влево
* `GET /cgi-bin/ptz?action=right&speed=5` — поворот вправо
* `GET /cgi-bin/ptz?action=stop` — остановка привода

### 3. Снимок кадра в JPEG (`/cgi-bin/snapshot`)
* `GET /cgi-bin/snapshot` — моментальный снимок текущего кадра в формате JPEG для уведомлений в Telegram или панели Home Assistant.

### 4. Статус камеры (`/cgi-bin/status`)
* `GET /cgi-bin/status` — возвращает системную информацию (IP, память, аптайм, нагрузку).

## 💾 Установка прошивки на камеру

Прошивка разделов `custom` (`mtd4`, 192 КБ) и `web` (`mtd3`, 128 КБ) выполняется безопасно «в один клик» с обычной карты памяти MicroSD. Системный загрузчик (`u-boot`) и ядро (`romfs`) не перезаписываются, что гарантирует **защиту от окирпичивания**.

### Пошаговая инструкция:
1. Скачайте архив **`cleancam_sd_installer.zip`** из раздела [Releases](../../releases).
2. Возьмите карту MicroSD (объемом от 1 ГБ до 64 ГБ) и отформатируйте её в **FAT32**.
3. Распакуйте все файлы из архива прямо в корень карты памяти:
   ```text
   [Корень MicroSD]/
   ├── xm_autorun.sh       # Скрипт автоматического обновления
   ├── xm_flasher          # Автономный прошивальщик SPI Flash
   ├── busybox             # Утилиты командной строки
   ├── custom-x.squashfs   # Образ раздела конфигурации и сервисов (mtd4)
   └── web-x.squashfs      # Образ раздела веб-интерфейса и CGI (mtd3)
   ```
4. Вставьте карту памяти в слот **выключенной** камеры.
5. Подключите питание камеры. Скрипт `xm_autorun.sh` выполнит следующие действия:
   * Запустит Telnet на порту 23.
   * Очистит и прошьет разделы `/dev/mtd4` и `/dev/mtd3`.
   * Перезагрузит камеру в новую чистую систему CleanCam OS (весь процесс занимает ~20–30 секунд).
6. Извлеките карту памяти.
7. Откройте в браузере `http://<IP_КАМЕРЫ>/` (логин: `admin`, пароль: `admin`).

> [!NOTE]
> Если пароль был изменен и забыт, либо камера потеряла Wi-Fi сеть, удерживайте аппаратную кнопку **Reset** в течение **10 секунд** — камера сбросит пароль на `admin` и восстановит стандартную точку доступа для первичной настройки.

## 🛠️ Локальная сборка проекта

### Требования к окружению:
* **Python** 3.8 или новее
* **Zig** компилятор (версии `0.11.0` - `0.14.0`) — используется для мгновенной кросс-компиляции исходников на Си под архитектуру ARM (`arm-linux-musleabihf`).
* **squashfs-tools** (`mksquashfs` с поддержкой сжатия `xz`):
  * На Linux (Ubuntu/Debian): `sudo apt-get install squashfs-tools`
  * На Windows: готовые бинарники `mksquashfs.exe` находятся в `tools/squashfs-tools/`

### Запуск сборки:
Для сборки всех компонентов достаточно выполнить одну команду в корне проекта:

```bash
python build.py
```

### Что делает мастер-скрипт сборки:
1. Кросс-компилирует через `zig cc` статические ARM-бинарники:
   * `xm_rtspd` (RTSP стример + ONVIF демон)
   * `xm_auth` (CGI аутентификации и сессий)
   * `xm_resetd` (демон отслеживания кнопки сброса)
   * `xm_snap` (генератор JPEG-кадров)
   * `xm_setcfg` (модуль управления параметрами видеосенсора)
2. Упаковывает раздел `build_clean/custom-x` в `custom-x.squashfs` (строгий лимит: 196 608 байт).
3. Упаковывает раздел `build_clean/web-x` в `web-x.squashfs` (строгий лимит: 131 072 байт).
4. Проверяет права доступа файлов (`rwxr-xr-x` для скриптов и исполняемых файлов).
5. Формирует U-Boot legacy образы (`.squashfs.img`).
6. Собирает готовый к записи архив **`dist/cleancam_sd_installer.zip`**.

## 🚀 Непрерывная сборка (CI/CD GitHub Actions)

В проекте настроен автоматический пайплайн сборки и публикации в GitHub Releases (`.github/workflows/build-and-release.yml`):

1. **Автоматическая проверка и сборка:** запускается на каждый push в ветки `main`/`master` и Pull Request.
2. **Публикация релизов по тегам:**
   При создании тега версии (например, `v1.0.0`):
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   GitHub Actions автоматически:
   * Развернет чистое окружение на базе Ubuntu.
   * Установит `squashfs-tools` и компилятор `zig`.
   * Соберет прошивку.
   * Создаст **GitHub Release** с прикрепленным архивом `cleancam_sd_installer.zip` и отдельными squashfs-образами.
3. **Ручной запуск:** на вкладке **Actions** в веб-интерфейсе GitHub доступна кнопка **Run workflow** с возможностью собрать релиз в один клик.
