# CleanCam OS: Кастомная прошивка для Wi-Fi камеры ICSee (GK7201V300)

Полностью очищенная кастомная сборка прошивки для поворотной Wi-Fi камеры на базе процессора **Goke GK7201V300** и Wi-Fi чипа **SSV6158M**.

---

## 1. Что изменено в кастомной прошивке CleanCam

### Удалено (Очистка от мусора и слежки):
* **Китайские облачные сервисы и телеметрия:**
  * Заблокированы домены `push.umeye.cn`, `secu100.net`, `pub-tcs.secu100.net`, `cloud.xmeye.net`, `d.xmeye.net`.
  * В конфигурации включен флаг `DisableXmServerConn: true` (отключение соединения с серверами Xiongmai).
  * Отключены фоновые демоны сотовой связи и телеметрии (`XmMobileDaemon`, `Xm4gDialer`).
  * Удален демон сопряжения по Bluetooth (`XmBle_SsvApp_6158M`).
* **Мусорные медиафайлы:**
  * Удалены 43 тяжелых аудиофайла голосовых подсказок на разных языках из `/usr/share/music/` (освобождено ~850 КБ флеш-памяти).
  * Удалены фоновые картинки интерфейса экрана LVGL из `/mnt/custom/data/LVGL/` (камера не имеет физического дисплея).
  * Удалены ненужные шрифты и таблицы строк на 30 языках.
* **Принудительные перезагрузки:**
  * Отключен таймер принудительной ночной перезагрузки `automaintainreboot`.

### Добавлено и разблокировано:
* **Полный Root-доступ:**
  * Сброшен системный пароль `root` (мгновенный вход без пароля).
  * Автоматический запуск сервера **Telnet на порту 23** при включении камеры.
  * Резервный шелл через netcat на порту 2323.
* **Современный HTML5 Web-интерфейс (порт 80):**
  * Заменен устаревший сайт с плагином ActiveX на быстрый адаптивный веб-интерфейс, работающий во всех браузерах (Chrome, Firefox, Safari, iOS, Android).
  * Интерактивный виртуальный джойстик PTZ (поворот, наклон, регулировка скорости).
  * Переключение ночных режимов (Умный Dual-Light, Ч/Б ИК, Цветной).
  * Управление белым светодиодным прожектором (Вкл, Выкл, Авто).
* **Прямые HTTP API для управления:**
  * `/cgi-bin/opptz.cgi` — прямое управление приводами PTZ через HTTP POST.
  * `/cgi-bin/setconfig.cgi` — настройка экспозиции, яркости, контрастности и ночного режима.
  * `/cgi-bin/getinfo.cgi` — получение состояния системы.
* **Оптимизация памяти:**
  * Настроены параметры подкачки и сброса кэша под 64 МБ RAM для устранения задержек видеопотока.

## 2. Готовые файлы в проекте

* **`General_IPC_GK7201V300_CLEANCAM_CUSTOM.bin`** — полный упакованный образ кастомной прошивки в формате Xiongmai.
* **`sd_card_installer/`** — папка для прошивки «в один клик» с MicroSD карты:
  * `custom-x.squashfs.img` — очищенный раздел конфигурации со скриптом `extapp.sh`.
  * `web-x.squashfs.img` — раздел с современным HTML5 веб-интерфейсом.
  * `user-x.squashfs.img` — очищенный системный раздел (без аудио-мусора).
  * `xm_autorun.sh` — скрипт автоматической прошивки SPI Flash памяти.

## 3. Инструкция по прошивке камеры

Так как в заводской прошивке `V5.04` включена проверка цифровой подписи RSA, обновление через китайское приложение iCSee заблокировано. Самый надёжный и безопасный способ прошивки — **через MicroSD карту**.

### Пошаговый процесс:
1. Возьмите карту MicroSD (от 1 ГБ до 64 ГБ) и отформатируйте её в **FAT32**.
2. Скопируйте все файлы из папки `sd_card_installer/` прямо в корень карты памяти:
   ```
   [Корень карты памяти]/
   ├── xm_autorun.sh
   ├── busybox
   ├── flash_unlock
   ├── flash_erase
   ├── custom-x.squashfs.img
   ├── custom-x.squashfs
   ├── web-x.squashfs.img
   ├── web-x.squashfs
   ├── user-x.squashfs.img
   └── user-x.squashfs
   ```
   ├── xm_autorun.sh
   ├── custom-x.squashfs.img
   ├── web-x.squashfs.img
   └── user-x.squashfs.img
   ```
3. Вставьте карту в выключенную камеру и подключите питание.
4. Камера загрузится и автоматически запустит скрипт `xm_autorun.sh`:
   * Скрипт создаст **полный бэкап оригинальных заводских разделов** в папку `factory_backup/` на карте памяти.
   * Очистит и прошьёт модернизированные разделы напрямую в микросхему SPI Flash (`mtd2`, `mtd3`, `mtd4`).
   * В лог-файл `flasher.log` запишется отчет о завершении.
5. Подождите 60–90 секунд, затем извлеките карту памяти и перезагрузите камеру по питанию.

## 4. Использование камеры после прошивки

### Подключение по Telnet (Root доступ)
```bash
telnet <IP_КАМЕРЫ> 23
# Логин: root
# Пароль: не требуется (нажмите Enter)
```

### Веб-интерфейс
Откройте в браузере: `http://<IP_КАМЕРЫ>/`
Вам откроется чистый веб-интерфейс с живым видео, управлением поворотом PTZ и настройками подсветки.

### Сборка своей ревизии
Если захотите внести дополнительные правки в скрипты или веб-интерфейс, просто запустите сборщик:
```bash
python tools/build_custom_firmware.py
```
Скрипт автоматически пересоберёт образы разделов через `mksquashfs` с XZ-сжатием и подготовит файлы для прошивки.
