⚡ Мгновенные Push-уведомления поверх видео:
Home Assistant может мгновенно выводить предупреждения поверх видеопотока через REST GET запрос без указания порта 8080:
GET http://[IP_камеры]/cgi-bin/osd_push?line1=ВНИМАНИЕ!&line2=Движение+у+ворот&duration=10&color=red&x=100&y=100
Параметры: line1..line6 (текст), duration (сек), color (red, yellow, green, cyan, white или 0xF0FF0000), x, y (координаты 0..8192), size (шрифт 16, 24, 32, 48).
